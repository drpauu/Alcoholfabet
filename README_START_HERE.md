# TECLA&PAU — COMENÇA AQUÍ

Aquest paquet està preparat per a **Codex amb Sol Ultra** i substitueix els prompts antics de Lovable i Opus.

## Passos

1. Descomprimeix el paquet a l'arrel del repositori actual.
2. Canvia la contrasenya de base de dades que es va compartir anteriorment.
3. Connecta Codex al projecte Supabase amb `setup/connect-supabase-codex.ps1`.
4. Obre Codex des de l'arrel del repositori.
5. Enganxa `PASTE_THIS_IN_CODEX.txt`.
6. Permet que inspeccioni, executi, modifiqui i provi el projecte.

No enganxis de nou tots els documents al xat: l'agent els pot llegir des del repositori.
