# Motion Lab

Obre `index.html` en un servidor local per veure i sentir els efectes.

Exemple:

```bash
python -m http.server 8080
```

Després obre:

```text
http://localhost:8080/motion/motion-lab/
```

Aquest laboratori és una referència, no el producte final. Codex ha de traslladar les seqüències al sistema de components real i sincronitzar-les amb `state_version` i els esdeveniments confirmats de Supabase.
