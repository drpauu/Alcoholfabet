# Starter files

Aquests fitxers no són una aplicació completa. Són peces de domini i estil que l'agent pot copiar o adaptar al projecte real.

Inclouen:

- tipus TypeScript;
- configuració de durada;
- generador determinista de tauler;
- regles pures;
- màquina d'estats inicial;
- copy català;
- design tokens;
- animacions CSS;
- exemples de tests.

Dependències recomanades, sense versions fixades:

- `react`.
- `react-dom`.
- `react-router-dom` o router equivalent.
- `@supabase/supabase-js`.
- `zod` per validar fronteres de dades.
- `vitest`.
- `@playwright/test`.

L'agent ha d'utilitzar versions estables compatibles amb l'entorn, no copiar versions antigues d'aquest document.
